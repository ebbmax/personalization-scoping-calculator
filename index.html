🌐 Web Personalization

To help estimate the number of personalization credits required for decisioning, we need to understand the number of websites where personalization will be applied and the associated MUVs for each website. We currently use the following formula to estimate the number of decision credits required per MUV on each site: Personalization Credits = MUVs × 8 Decisions Per MUV × 12 Months × Contract Length.

📱 Mobile App Personalization

Similar to the above, in order to scope the number of credits necessary to power mobile app personalization we need to understand the number of mobile apps requiring personalization and their associated Monthly Active User Counts. The same formula from web is applied for credit estimation.

📧 Email Personalization

For customers that are leveraging Marketing Cloud Advanced, Personalization recommenders are available for use to power individualized recommendations in email. To estimate the amount of credits required, we need to understand the approximate number of emails sent per month that contain recommendations. The formula we use to estimate the number of credits required is the following: Personalization Credits = Number of Monthly Emails × % of Emails Using Recommendations × 1.25 × 12 Months × Contract Length.

👤 Marketing Cloud Personalization — Named Profiles

Since the customer owns and is actively using Marketing Cloud Personalization, we need to understand the number of Named Profiles in their MCP instance. This is used to recommend the correct quantity of the Named Profiles SKU. The formula is: Named Profile Units = Named Profiles ÷ 100,000.

🛒 Retail Triggers

Based on the desire to execute a set of retail triggers, the MCP+ SKU is a potential option. In order to include this SKU, we need to understand the number of named profiles (contacts) the customer has across brands / domains to generate an accurate BOM recommendation.

⚠️ Data Cloud Prerequisite for Salesforce Personalization

To leverage Salesforce Personalization for web and/or mobile app personalization, the customer must own one of the following Data Cloud entitlement combinations:

  • Option 1: Data Services Credits + Sub-Second Real-Time Profiles
  • Option 2: D360 Profiles + Flex Credits (for Real-Time event consumption)

Please ensure the customer has the appropriate Data Cloud entitlements before finalizing this quote. Data Cloud scoping guidance and materials are available in the #help-grow-real-time-data-cloud Slack channel canvas.
